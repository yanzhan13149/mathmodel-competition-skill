# 每次调用的环境检查与文献入口

每次激活本技能时执行，包括首次开赛、跨会话续做、单问修订和论文审查。先读当前比赛状态，保留已完成工作；只复核环境与当前任务需要的证据，不重跑十阶段流程。没有终端或本机操作能力时执行能做的检查，其余记录为待人工验证。

## 三项检查

| 检查 | 实际操作 | 通过所需证据 |
|---|---|---|
| 网络与赛事文件 | 访问已确认的当届赛事官网；在官方测试或草稿入口验证文件上传，下载并打开官方公开附件 | 实际 URL、时间、浏览器或执行记录；上传、下载分别记录 |
| Word | 在 Microsoft Word 或用户指定的兼容编辑器中打开测试 DOCX，编辑、另存并重新打开；需要交付 PDF 时验证导出 | 实际应用名称、测试文件、操作记录或队员本轮确认 |
| 浏览器与文献 | 用可用浏览器逐一打开下表四个入口；需要文献时执行相关关键词检索并检查 OA 全文 | 页面或浏览器证据、访问时间、可访问/受限/待验证，以及实际文献记录 |

文件上传只使用已授权会话及明确的测试/草稿入口，不点击正式提交，不把比赛资料上传到无关测试网站。没有安全测试入口就记录“上传待验证”；已经授权的操作不重复询问。下载应验证文件实际保存且可打开，不能仅依据首页响应判为通过。

具备本机操作工具时实际验证 Word；仅安装了 Python 的 DOCX 库、生成了文件或发现应用路径，不代表 Word 已正常打开和保存。DeepSeek App 模式由队员在电脑执行本机检查，再回传证据。

## 轻量 HTTP 探测

在独立比赛工作目录中执行，脚本路径从已安装的技能根目录解析：

```text
python <SKILL_ROOT>/scripts/check_readiness.py --workspace . --official-url <已确认的赛事官网URL>
```

官网尚未确认时省略 `--official-url`，保留待确认状态。脚本只使用标准库，以有界 GET 请求探测官网和四个文献入口，报告保存在 `state/readiness/latest.json`。`--skip-network` 用于明确离线环境或维护测试，跳过项不能记为通过。

脚本退出码 0 表示诊断报告写出，**不表示所有环境检查已通过**。`http_reachable` 只证明本次 HTTP 请求成功；403、418、429、验证码等记录为 `restricted` 或访问受限。脚本不会执行浏览器登录、Word 操作、文件上传或正式提交；这些项目在没有独立证据时保持 `pending_manual`。

每次调用都生成本轮报告，实际浏览器/队员证据另记到 `decision_log.startup_checks.manual_evidence`，每项包含检查名、状态、核对时间、来源与证据位置。同步 `checked_at`、`report_path` 和综合 `overall_status`，不把历史快照或脚本的 0 退出码冒充新证据。旧版状态没有 `startup_checks` 时补充该可选字段，不重初始化状态。只有当前任务所需项目都有实际证据时才能记为就绪。

受限项应简短说明原因并继续不依赖它们的工作；不要因某个出版平台拦截自动请求就阻止读题或本地求解。只在当前任务确实依赖缺失项时集中补问，不重复追问已提供的信息。

## 每次可用的文献入口

| 平台 | 规范入口 | 查找方式 |
|---|---|---|
| MDPI | https://www.mdpi.com | 站内搜索或 `site:mdpi.com <模型名与主题关键词>` |
| Springer | https://link.springer.com | 站内搜索或 `site:link.springer.com <关键词>`；记录实际官方跳转 |
| Elsevier ScienceDirect | https://www.sciencedirect.com | 站内搜索或 `site:sciencedirect.com <关键词>`，逐篇检查开放获取状态 |
| IEEE Xplore | https://ieeexplore.ieee.org | 站内搜索或 `site:ieeexplore.ieee.org <关键词>`，逐篇检查开放获取状态 |

这些是检索入口，首页可访问不代表每篇文章都开放获取。需要模型依据或论文引用时，按 `tools/paper_search/SKILL.md` 执行四站定向发现与现有双引擎交叉核验；只有与问题相关且来源可核对的文献才进入参考文献。保留题名、作者、年份、DOI、原始出版页、OA 状态、全文或下载位置及检索日期。当前任务无需查文献时只检查入口，不进行无关检索。

仅下载出版方明确开放的全文或可确认合法的 OA 版本。付费、登录、验证码或自动请求限制如实记录，使用已有合法访问方式或补充来源，不绕过限制、不虚构引用或下载成功记录。
