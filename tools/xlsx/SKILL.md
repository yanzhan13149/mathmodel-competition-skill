# Excel 工具接口

这是本仓库独立编写的接口说明，不附带上游专有 Excel 脚本。本版不提供 recalc.py。

优先使用当前环境的表格技能并读取说明；独立环境可安装 pandas 与 openpyxl。先检查工作表、表头、单位、缺失值和日期，再按实际范围导入。不要修改原始附件；清洗过程和结果表写入比赛目录。

openpyxl 不会计算公式。存在公式时，核对缓存值是否新鲜；需要重算时使用已安装的 Excel、LibreOffice 或可用的表格计算服务，并检查实际结果。重算失败不覆盖原件，也不把旧缓存当作最新结果。输出公式错误、单位与计算结果的检查记录。
