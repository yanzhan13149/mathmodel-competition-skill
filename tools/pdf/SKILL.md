# PDF 工具接口

这是本仓库独立编写的接口说明，不附带第三方 PDF Skill 代码。

先使用环境提供的 PDF 能力并读取其使用说明。没有现成工具时，可使用自行安装的 pdfplumber 或 pypdf 提取文本；扫描页需要可用的 OCR。公式、表格和复杂排版必须对照实际页面，不将文本提取成功当作视觉核验。

题目和原始附件保持只读，提取物写入比赛目录。记录输入路径、页码和提取限制。交付论文时读取实际编译 PDF，核对摘要、正文、附录、页数、匿名与字体；根目录 `scripts/latex_check/check_pdf.py` 可作自动预检，不能替代页面检查。
